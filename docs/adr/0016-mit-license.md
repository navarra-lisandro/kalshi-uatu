# ADR-0016: MIT license

- **Status:** Accepted
- **Date:** 2026-11-26

## Context
The repo is public and serves as a portfolio piece (ADR-0002). Without a license, the code is visible but legally not reusable.

## Decision
License the engine under **MIT**. Strategy material is never in the repo, so the license does not cover it.

## Consequences
- Maximum readability and reuse; widely recognized by recruiters and contributors.
- No patent grant or trademark clause; accepted, since the value is in the private strategy, not the engine.
